### ✨ What's New (User-Friendly)
- **Fixed Full-Screen Cover Viewer & Clean Zoom Viewing:** Tapping a cover on any Details page now opens inside the true full-screen safe area so the title, close button, and **Customize Artwork** button stay comfortably away from screen edges and gesture bars. Pinching or double-tapping to zoom in automatically tucks away the title, X button, **Customize Artwork** button, and dark top/bottom vignettes so nothing blocks your view; tapping once brings them right back.
- **Separate Cover & Banner Artwork Priorities (+ Built-In Best Defaults):** Under **Settings → Artwork & Metadata Sources**, you can now switch cleanly between **Covers** (vertical posters and square box art) and **Banners** (16:9 widescreen headers and Home Showcase backdrops). Each medium now ships with tailored recommended defaults for both Covers and Banners.
- **Safe Artwork Cache Reset Options:** Added a **Cache** reset menu inside Artwork & Metadata Sources with two safe options — quickly clear temporary image downloads, or clear cache and re-fetch auto-loaded banners with your new priority order. Custom user covers, custom banners, and manual banner framing are always left completely untouched.
- **Live API Key Verification + Free OMDb Ratings:** Pasting text into **AI & Artwork Boosters** no longer shows a fake checkmark just because text was typed. Tap **Test** on any key/pair (or **Test All** in the header) to verify keys live against their servers. Also added optional free **OMDb API Key** support as a backup source for IMDb, Rotten Tomatoes, and Metascore ratings.
- **Official Tracker Logos Everywhere:** Replaced plain two-letter monogram boxes and broken-link placeholders in **Tracker Accounts** settings and the **Trackers** switcher sheet with each service's crisp official brand logo.
- **Strict Category Rating Isolation:** Stopped IMDb, TMDb, Trakt, Rotten Tomatoes, and Metacritic ratings from leaking onto Manga, Light Novels, Web Novels, Books, Comics, Games, Visual Novels, or Fanfiction. Each category now keeps strictly to its own rating sources.
- **Hide & Restore Specific Entry Ratings:** Long-press any rating badge on a Details page to hide it for that entry, or manage all available badges under **Options → Manage Ratings**. Changes sync automatically between the entry's Details page and the Home Showcase banner until you turn a rating back on.
- **Universal Books-Style Text-Only Layout:** Added a clean, thumbnail-free **Text Checklist** layout mode inspired by Books tracking across Series/Anime episodes, Manga/Novel chapters and volumes, and Comic issues — available in **Episode Layout Settings** and the quick layout toggle button.
- **Fewer Redundant Background Requests:** Prevented unnecessary repeat update checks when returning to Home and stopped duplicate discussion comment requests when opening Anime/Manga Details.

### 🔧 Technical Details
- **In-Window Cover Viewer (`FullScreenCoverViewerDialog.kt`, `DetailScreen.kt`):** Replaced `Compose Dialog` (`decorFitsSystemWindows = false` separate window where `WindowInsets` reported empty `navigationBars` bounds on Android 15) with an in-window `zIndex(100f)` overlay moved outside `DetailScreen`'s swipe/scroll transform container (`BoxWithConstraints`), reading Activity `WindowInsets.safeDrawing` (`Top + Horizontal` and `Bottom + Horizontal`), adding `BackHandler`, removing outer `AsyncImage` padding, and auto-toggling `showControls` when zoom exceeds `1.03f` (and restoring on zoom reset or tap).
- **Split Cover & Banner Priority Engine (`PreferenceManager.kt`, `ArtworkWaterfallRepository.kt`, `ArtworkPriorityScreen.kt`, `DetailViewModel.kt`, `CoverCache.kt`, `BackdropFocus.kt`):**
  - Added DataStore keys `banner_priority_<mediatype>` and `banner_disabled_sources_<mediatype>`, dedicated banner flows/resetters, and tailored cover vs banner defaults (`getDefaultSourcesFor` vs `getDefaultBannerSourcesFor`).
  - Updated `ArtworkWaterfallRepository.searchArtworkCandidates` & `sortForType` to sort and filter `isBanner = false` vs `isBanner = true` candidates independently using cover vs banner priority & disabled sets.
  - Updated `DetailViewModel.resolveUpgradedTmdbBanner` to read `getBannerArtSourcePriority` & `getBannerDisabledArtSources`.
  - Added `CoverCache.clearNonCustomCache()` (strictly skipping `covers/custom/`), `BackdropFocusCache.clear()`, `ArtworkWaterfallRepository.clearMemoryCache()`, `EnrichmentRepository.clearMemoryCaches()`, and the 2-option `Reset Artwork Cache` `ModalBottomSheet` in `ArtworkPriorityScreen` (never modifying entries with `isCustomEntry`, non-blank `customCoverPath`/`customBannerPath`, or `artworkRole != "DEFAULT"`).
- **Real Live Key Validation & OMDb (`ApiKeyValidator.kt`, `ApiKeyConfigSheet.kt`, `EnrichmentRepository.kt`, `OmniTrackApplication.kt`):**
  - Created `ApiKeyValidator` with real 8-second authenticated HTTP pings for Gemini, OpenRouter, TMDb (v3 query & v4 Bearer), Fanart.tv, SteamGridDB, IGDB/Twitch OAuth pair, MDBList, OMDb, Comic Vine, and Metron Basic Auth pair.

  - Added DataStore JSON map `HIDDEN_RATING_SOURCES_MAP` keyed by `PreferenceManager.ratingVisibilityKey(...)` (overloads for `MediaItemEntity`, `MediaCardSummary`, `SearchResultItem`) with long-press hide confirmation dialog and `Options → Manage Ratings` toggle sheet synced directly to `HeroRatingStrip`.
