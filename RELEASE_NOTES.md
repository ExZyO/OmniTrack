### ✨ What's New (User-Friendly)
- **Crisp, Unblurred Visual Novel & Fallback Banners When Blur Is Off:** When you set **Hero Banner Blur** to **Off** (globally or per category), Discover and Home hero banners now render sharp and unblurred—even when a Visual Novel or other title falls back to clean cover artwork instead of a wide banner. When you do choose Subtle, Medium, or Heavy blur, that exact blur strength is respected everywhere.
- **No More Crushed or Vertical Pill Badges:** Fixed the **DISCOVER** badge on rows like *Browse by Streaming Service* inside **Home Page Shelves & Display** so badges never wrap onto a second line or squeeze vertically. Applied the same layout fix across customization blur selectors, *Daily Critics' Pick*, Home Hero tags, shelf headers, *Seasons Studio*, and episode/chapter pills.

### 🔧 Technical Details
- **Respect `HeroBannerBlurLevel.OFF` on Cover Fallbacks (`DiscoverView.kt`, `HomeDashboardView.kt`, `HomeCustomizerSheet.kt`):**
  - Removed the hardcoded minimum blur floors (`maxOf(bannerBlurDp, 18/10)` in `DiscoverSpotlightBanner` and `if (bannerBlurDp > 0) maxOf(data.bannerBlurDp, 16) else 20` in `HomeHeroSlideBackground`) so fallback cover backdrops only apply `Modifier.blur(bannerBlurDp.dp)` when `bannerBlurDp > 0`, with clean top-aligned `Alignment.TopCenter` framing and higher legibility alpha when crisp.
  - Updated the *Allow Cropped Cover Fallback* toggle description in `HomeCustomizerSheet` to reflect that cover fallbacks now follow the user's blur setting.
- **Prevent Crushed/Vertical Trailing Badges in Flex Rows (`HomeCustomizerSheet.kt`, `DiscoverCustomizerSheet.kt`, `VisualPresentationScreen.kt`, `DiscoverEnhancements.kt`, `HomeDashboardView.kt`, `SeasonMergeCustomizeSheet.kt`, `DetailSeriesContent.kt`, `DetailFanficTrackingSection.kt`):**
  - Added `Modifier.weight(1f, fill = false)` with `maxLines = 1, overflow = TextOverflow.Ellipsis` on leading labels in horizontal rows alongside fixed badges, and `maxLines = 1, softWrap = false` on compact pills (`DISCOVER`, `#rank/OFF`, `Inherit (...)` with `1.45f` flex weight, blur level chips, `Turn All On/Off`, `Merge All`, hidden season counts, `RECAP`/`FILLER`, `PAID`, and `Open`/`+ Library`).
